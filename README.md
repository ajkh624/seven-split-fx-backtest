# 세븐스플릿 USD/KRW 백테스트

박성현 작가의 **세븐스플릿(Seven-Split)** 전략을 USD/KRW 환율에 적용한 클라이언트 사이드 백테스트.

## 전략 핵심 (정통 세븐스플릿)
- **1번 계좌 = 장기 투자**: 시작 시점 즉시 매수, 큰 수익(예: +20%) 도달 시에만 익절
- **2~7번 계좌 = 단기 트레이딩**: 1번 매수가 기준 -1%, -2%, -3%, -4%, -5%, -6% 분할 매수, 각자 매수가 +1% 익절
- 하락장에서도 단기 회전으로 현금흐름 창출, 1번은 미스터마켓 무시
- 매도 대금은 그대로 회수 (현 자본 기준 회전, 복리 자연 반영)

## 가정
- 거래수수료, 환전 스프레드, 슬리피지 = 0
- 일봉 OHLC 기준, 매수=저가 도달 시 / 매도=고가 도달 시 체결
- 데이터: Yahoo Finance `KRW=X` 일봉 (2,950일)

## 사용법
1. https://ajkh624.github.io/seven-split-fx-backtest/ 접속
2. 빠른 기간 / 시장 국면 버튼 또는 직접 날짜 입력 (자동 재실행)
3. 결과 카드 + 차트 + 거래내역 확인
