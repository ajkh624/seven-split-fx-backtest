# 세븐스플릿 USD/KRW 백테스트

박성현 작가의 **세븐스플릿(Seven-Split)** 전략을 USD/KRW 환율에 적용한 클라이언트 사이드 백테스트 도구입니다.

## 전략 요약
- 자금을 N개(기본 7개) 트랜치로 균등 분할
- 기준가 대비 -1%, -2%, -3% ... 단계마다 트랜치를 매수
- 각 트랜치는 매수가 대비 +1% 도달 시 익절 매도
- 매도 후 트랜치 시드는 다시 사용 가능, 기준가는 직전 청산가로 갱신(rolling) 또는 시작가 고정(fixed) 선택

## 가정
- 거래수수료, 환전 스프레드, 슬리피지 = 0
- 일봉 OHLC 기준, 매수는 저가 도달 시 / 매도는 고가 도달 시 체결
- 데이터 출처: Yahoo Finance `KRW=X` 일봉

## 사용법
1. [GitHub Pages 배포 URL](#) 접속
2. 파라미터 조정 후 **백테스트 실행**
3. 거래 내역 CSV 다운로드 가능

## 로컬 실행
```bash
python3 -m http.server 8000
# http://localhost:8000
```
